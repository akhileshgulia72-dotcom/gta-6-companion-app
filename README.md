# 🎮 GTA 6 Companion App

A Flutter-based companion application designed to provide GTA 6 fans with useful information, news, characters, vehicles, maps, quizzes, and interactive features in one place.

 📱 Features

- ⏳ GTA 6 release countdown
- 📰 GTA 6 news section
- 👥 Character information
- 🚗 Vehicle information
- 🗺️ Interactive map section
- 🧠 GTA 6 quiz
- 🎁 Lucky Draw feature
- 🎬 Splash screen and custom UI
- 📱 Responsive Flutter interface
- 🔥 Firebase integration
- 📢 Rewarded advertising integration
 🛠️ Tech Stack

- **Flutter**
- **Dart**
- **Firebase**
- **Google Mobile Ads**
- **REST API / News API integration**
- **Android Studio / VS Code**
- **Git & GitHub**
